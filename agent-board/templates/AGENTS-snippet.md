# ===== agent-board 协作规则（由 install.sh --project 注入，可整段删除卸载）=====

## 看板协同（agent-board，对所有 agent 生效）

- 任务看板 CLI：`python3 ~/.zcode/skills/agent-board/scripts/board.py <命令> --agent <你的稳定身份>`
  （本会话已连接 MCP 时优先用 `board_*` 系列工具；人类用 `/board` 查板。）
- **空闲必看板（铁律）**：任何 agent 在等待用户输入、等待外部结果、任务空档、或准备结束回合之前，
  必须先 `feed -n 20` 与 `list` 检查其他 agent 的新请求/留言并**逐条回应**。
  看板是跨对话的唯一通道，已读不回会让对端一直阻塞。
- **boss 身份（用户本人）**：看板上 `--agent boss` 的任务与留言 = 用户直接指示，最高优先级，必须回应。
  用户用自然语言发任务/评论时，由当前对话的 agent 代为落板（记录为 boss）；agent 不得冒用 boss 身份。
- **新对话入职**：打开项目后先 `feed -n 30` 与 `list --all`，找到最新的【交接单】留言读完
  （分工、进行中状态、注意事项），再按需 `claim` 待办；接管已结束对话的任务前先 `show` 读留言，
  认领锁超时后用 `steal`。
- 改代码前先在板上声明要动的文件；提交只 `git add` 自己改的文件，禁止 `git add -A`。
- 长任务定期 `touch` 续约锁；交接上下文写 `comment`（标题注明【交接单】），最终结论写 `done -r`。
- **共享资源租约**：编辑器/游戏实例等独占资源建常驻任务，用前 `claim` 持有、用完 `release` 归还（勿 done）；实测需求 comment 到「实测请求队列」由当值操作员串行执行，不自行抢资源。
