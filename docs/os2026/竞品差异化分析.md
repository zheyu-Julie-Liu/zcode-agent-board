# Agent Board 竞品差异化分析

**OSChina 2026 参赛文档 · 交付物②**

> 本文回答一个问题：市面上已有任务管理/协作工具，AI 多对话协作为什么还需要 Agent Board？
> 合规声明：本插件为独立开发，设计灵感来自项目所有者在其他 AI 工具生态使用看板的经验；文中对第三方产品的描述仅基于公开资料与类别特征，未参考其任何代码，无归属义务。

## 一、参照系概览

| 参照系 | 形态 | 与 Agent Board 的关系 |
|--------|------|----------------------|
| DeepSeek Harness（DSH）生态的看板插件（3 个同类） | 其他 AI CLI 生态的社区看板插件 | **同类竞品**：同为"AI agent 任务看板"，赛道最接近 |
| Claude Code 内置 TodoWrite/Task 系统 | 单对话内置任务列表 | **替代方案（受限）**：解决单对话内的任务编排，不跨对话 |
| Jira / Trello / Notion 等通用项目管理 | 人类团队 SaaS | **过度设计**：为人类团队设计，AI 无法零摩擦使用 |
| git issue / 项目看板 | 仓库托管方附带 | **粒度过粗**：面向人类评审的 issue 流，非 agent 运行时协作 |

## 二、逐项差异分析

### 2.1 vs DSH 生态看板插件（同类）

相同点：都承认"多 AI agent 需要共享任务板"这一方向。

Agent Board 的差异点：

1. **零依赖哲学**：纯 Python 标准库实现，无框架绑定、无外部服务；DSH 系插件依托其宿主生态，跨生态能力有限；
2. **并发安全下探到操作系统层**：任务认领与 ID 分配均用 POSIX `O_CREAT|O_EXCL` 原子原语，不依赖"约定式"互斥；
3. **租约语义完整**：`touch` 续约 + 锁 mtime 超时 `steal` 接管，显式建模"AI 工作者会掉线"；
4. **客户端无关**：CLI 零门槛 + skill 拷贝即装 + MCP 注册三层接入，已实测 ZCode 与 Codex 双客户端兼容，不绑死单一 harness。

### 2.2 vs Claude Code 内置 Todo（单对话方案）

内置 Todo 是**单对话内**的任务清单：对话关闭即消失，天生无法回答"另一个对话做到哪了"。

| 维度 | 内置 Todo | Agent Board |
|------|-----------|-------------|
| 作用域 | 单对话 | 跨对话 + 跨工具 |
| 生命周期 | 随对话结束消失 | 落盘项目根，持久留存 |
| 多 agent 互斥 | 无此概念 | POSIX 原子锁 |
| 掉线接管 | 无 | touch/steal 租约 |
| 人类可见性 | 需打开对话查看 | `/board` 一条命令看全局 |

结论：二者是互补关系而非替代——内置 Todo 管对话内步骤，Agent Board 管对话间协作。

### 2.3 vs 通用项目管理工具（Jira/Trello 等）

| 维度 | 通用 PM 工具 | Agent Board |
|------|-------------|-------------|
| 操作者 | 人类（UI 点击） | AI agent（一条 shell 命令） |
| 接入成本 | 需要 API token、字段映射 | 项目根放一个文件夹即用 |
| 并发语义 | 人类协作粒度，无进程级互斥 | 原子锁 + 租约 |
| 使用驱动力 | 靠人类纪律维护 | AI 由 skill 自动引导使用 |

通用工具的"看板"是给**人**看的；Agent Board 的看板是给 **AI 工作者**用的运行时基础设施，同时保留人类总览视图（board_overview.py）。

## 三、Agent Board 的五项核心差异点

1. **跨对话共享状态**：多个 AI 对话（可跨客户端）共享同一块持久化看板，互相看不见的问题被数据层面的共享直接消解；
2. **原子 claim 防抢单**：认领即 POSIX 抢锁，同瞬间多 agent 竞争必然有唯一胜者，无需人工仲裁；
3. **租约语义（touch 续约 / 超时 steal 接管）**：把"AI 工作者掉线"从灾难变成常规流程；
4. **boss 频道 + 人工总览双视图**：人类口述需求可由任意对话代为落板（boss 身份），人类用固定口径总览脚本消除信息切片偏差——人机混合团队的双向可见性；
5. **客户端无关**：CLI/skill/MCP 三层接入，ZCode 与 Codex 实测兼容，同类插件中跨生态能力独树一帜。

## 四、结论

在"AI 多 agent 协作"这个新兴赛道上，现有工具要么绑死单一生态（DSH 系插件）、要么只覆盖单对话（内置 Todo）、要么为人类而非 AI 设计（通用 PM 工具）。Agent Board 以**零依赖文件板 + POSIX 原子锁 + 租约语义 + 双视图 + 客户端无关**五项组合，填补了"跨对话、跨工具、人机混合"的 AI 运行时协作空白，并已经过真实多对话项目的全程实战检验。
