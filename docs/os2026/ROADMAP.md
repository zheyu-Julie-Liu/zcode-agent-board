# Agent Board ROADMAP

**OSChina 2026 参赛文档 · 交付物③**

> 版本基线：v0.2.x（当前发布线）。本文描述后续版本的规划方向，按社区反馈与真实使用需求动态调整。

## 设计原则

1. **真实需求驱动**：每个版本方向都来自实际多对话项目中的真实痛点，不做想象功能；
2. **零依赖不妥协**：核心永不引入强制外部服务，保持"文件夹即看板"的本质；
3. **客户端无关**：任何新能力同时覆盖 CLI / skill / MCP 三层接入。

## v0.3 —— 审核门禁与成果回退（规划中）

### 3.1 审核门禁（review gate）

- 新增任务状态流转：`done → review → 已确认`，交付不再自动闭环；
- 认领者提交 `done` 后任务进入"待审核"，由指定审核者（人类 boss 或指定 agent）`approve` 才最终闭环，`reject` 则打回待办池；
- 动机：真实使用中"agent 说做完了"不等于"真的做对了"，质量闭环需要显式的审核关卡；
- 设计渊源说明：项目所有者曾在其他 AI 工具生态使用过带强制审核的看板并获得启发——Agent Board 的审核门禁为独立设计，与其无任何代码血缘。

### 3.2 成果回退流程化

- `reject` 时不只打回任务，还支持挂接"回退动作"（如还原工作区改动、回收资源租约）；
- 回退动作以声明式配置描述，由看板执行或提示 agent 执行；
- 动机：交付被拒后，遗留的半成品状态若无流程化回退，会污染下一位认领者的工作起点。

## v0.4 —— 协作增强（方向）

- **多机同步**：`.agent-board/` 进 git 的协作模式标准化（冲突消解、锁的远端语义）；
- **看板查询语言**：`board query "status=todo & priority<=1 & claimed_by=空"` 式结构化筛选；
- **事件订阅**：events.jsonl 之上的 webhook/回调，任务状态变化可触发 CI 或通知。

## v0.5+ —— 生态（远期）

- 兼容矩阵扩展：更多支持 skill / MCP 协议的 AI CLI 实测认证；
- 模板库：常见协作协议（本项目中演化出的"boss 频道""编辑器租约""实测队列"等）沉淀为一键初始化模板；
- 案例征集：收录社区真实多 agent 协作案例（脱敏），反哺规则模板。

## 已交付里程碑

- **v0.1**：文件板 + CLI（add/claim/done/comment/feed）+ POSIX 原子锁；
- **v0.2**：MCP server（12 个 board_* 工具）+ skill 自动触发 + 租约语义（touch/steal）+ /board 人类命令 + board_overview.py 人工总览 + 市场发布（marketplace.json）。
